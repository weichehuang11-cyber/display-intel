# 人工更正資料夾

你確認過、但系統查不到的規格，填進 Excel 後上傳到這個資料夾，下次蒐集或週報就會生效。

**最方便的做法**：打開週報附件 Excel 的「人工更正」工作表（本週機型已預先填好品牌、機型、尺寸、解析度），在知道的格子填數值，存檔後上傳到這裡。也可以下載本資料夾的 `人工更正範本.xlsx` 自己填。

**上傳**：GitHub 網頁進入 `corrections` 資料夾 → 右上「Add file」→「Upload files」→ 拖曳檔案 → 按綠色「Commit changes」。手機瀏覽器也可以操作。

**規則**
- 品牌、機型必填（照週報上的名稱，大小寫、空白不影響）
- 空白＝不更動；填「清空」＝確認原本的數值是錯的、保持空白
- 「比對尺寸」「比對解析度」可指定只改某個螢幕選配
- 觸控填「是」或「否」；解析度寫成 2560x1600
- 來源說明會顯示在報告的出處（例如「供應鏈確認 2026-10」）
- 人工更正的數值以你為準，之後網路上的新聞都不會覆蓋
- 檔名隨意，可以放很多個檔案；也接受 CSV
- 格式有問題或找不到機型時，週報的「系統健康與資料查核」會提醒
